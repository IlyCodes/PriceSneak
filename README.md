# Price Sneak

**Price Sneak** is a comprehensive B2B SaaS platform designed for competitive intelligence and dynamic price monitoring. 

It enables e-commerce merchants to track competitor prices in real-time, configure intelligent dynamic pricing rules, and automate their market responses. Built on a scalable, polyglot architecture utilizing FastAPI (Python), React (TypeScript), PostgreSQL for relational data, and MongoDB for time-series price history.

---

### Tech Stack
* **Frontend:** React + Vite + TypeScript
* **Backend:** FastAPI (Python)
* **Databases:** PostgreSQL & MongoDB
* **Task Broker:** Celery & Redis
